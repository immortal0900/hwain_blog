GGUF는 한마디로 **"로컬 환경(내 컴퓨터)에서 LLM을 가장 쉽고 빠르게 돌리기 위해 만든 단일 파일 포맷"**입니다.

질문자님이 QLoRA로 학습시킨 모델은 보통 여러 개의 파일(어댑터, 설정값 등)로 나뉘어 있고 용량도 큽니다. 이를 **vLLM**이나 **llama.cpp** 같은 엔진에서 효율적으로 쓰기 위해 하나의 파일로 뭉치고 압축한 것이 바로 GGUF입니다.

---

## 1. GGUF의 원리: "다 들어있는 압축팩"

- **단일 파일 구조:** 모델의 가중치(Weights)뿐만 아니라, 토크나이저 설정, 모델 구조(Metadata) 등을 **파일 하나(.gguf)**에 모두 담습니다. 예전에는 모델 파일 따로, 설정 파일 따로 챙겨야 했지만 이제는 이 파일 하나만 있으면 바로 실행됩니다.
    
- **mmap(Memory Mapping) 최적화:** 파일을 읽을 때 메모리에 전부 올리지 않고, 필요한 부분만 빠르게 찾아 읽는 방식을 사용합니다. 덕분에 모델 로딩 속도가 비약적으로 빠릅니다.
    
- **진화된 양자화:** 앞서 배운 4-bit(NF4) 같은 기술을 더 확장해서 2-bit부터 8-bit까지 아주 다양한 압축 옵션을 제공합니다.
    

---

## 2. 사용 의도 및 근거 (왜 써야 하나?)

|**사용 의도**|**상세 근거**|
|---|---|
|**자원 효율성**|**CPU에서도 돌아감.** 고가의 GPU가 없어도 RAM만 충분하다면 CPU의 연산 능력을 빌려 모델을 실행할 수 있습니다.|
|**배포 편의성**|파일 하나만 전달하면 끝입니다. 복잡한 파이썬 환경 설정 없이도 `llama.cpp` 같은 실행 파일 하나로 어디서든 구동 가능합니다.|
|**속도와 용량**|7B~9B 모델을 5GB 내외로 압축하면서도 지능 하락은 최소화합니다. 로컬 PC에서 실시간 답변을 받기에 최적입니다.|

## 3. GGUF를 쓰는 방법

크게 **"만드는 법"**과 **"실행하는 법"**으로 나뉩니다.

### ① 만들기 (Conversion)

질문자님이 학습시킨 모델(SafeTensors 형식)을 GGUF로 바꿔야 합니다. 보통 `llama.cpp` 라이브러리의 스크립트를 사용합니다.

Bash

```
# 1. 모델 포맷 변환 (FP16/BF16으로 우선 통합)
python convert_hf_to_gguf.py /내/모델/경로 --outfile my_model_f16.gguf

# 2. 4비트 양자화 적용 (용량 줄이기)
./llama-quantize my_model_f16.gguf my_model_q4_k_m.gguf Q4_K_M
```

### ② 실행하기 (Inference)

만들어진 `.gguf` 파일을 실행하는 도구는 아주 많습니다.

- **vLLM:** 서버용으로 쓸 때 (앞서 설명드린 고성능 엔진)
    
- **llama.cpp:** 가장 가볍게 터미널에서 실행할 때
    
- **Ollama:** "ollama run" 명령어 한 줄로 맥/윈도우에서 앱처럼 쓸 때
    
- **LM Studio:** 코딩 없이 GUI 화면으로 모델을 채팅창처럼 쓰고 싶을 때

## 4. 요약: 언제 GGUF를 선택하나?

- **QLoRA/Unsloth:** 모델을 **가르칠 때(학습)** 씁니다.
    
- **GGUF:** 학습이 끝난 모델을 **실제로 서비스하거나 내 컴퓨터에서 가볍게 돌릴 때(배포/추론)** 씁니다.
    

결국 질문자님의 프로젝트 흐름은 다음과 같이 완성됩니다.

1. **Unsloth + NF4**로 보이스피싱 데이터를 빠르게 학습시킨다.
    
2. 결과물을 **GGUF** 포맷으로 변환하여 압축한다.
    
3. **vLLM**이나 **Ollama** 서버에 올려서 **FastAPI**와 연결해 실시간 탐지 서비스를 운영한다.
    

**이제 학습된 모델을 GGUF로 변환하는 구체적인 파이썬 스크립트나, 변환된 모델을 Ollama에 등록하는 방법이 궁금하신가요?**
