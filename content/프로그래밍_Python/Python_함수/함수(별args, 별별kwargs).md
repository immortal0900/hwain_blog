*args, **kwargs
**"개수 정해두지 말고, 주는 대로 다 받아라"**라는 의미를 담은 **가변 인자(Variable Arguments)** 문법


함수를 정의하거나 호출할 때, 인자를 몇 개나 넘길지 미리 알 수 없거나 유연하게 대처하고 싶을 때 사용합니다.

---

### 1. `*args` (Arguments)

- **형태:** 여러 개의 인자를 **튜플(Tuple)** 형태로 묶어서 받습니다.
- **특징:** 이름(Key) 없이 값만 순서대로 넘길 때 사용합니다.
- **비유:** "그냥 필요한 거 장바구니에 다 담아와!"
```Python
def add_all(*args):
    # args는 (1, 2, 3) 형태의 튜플이 됨
    return sum(args)

print(add_all(1, 2, 3)) # 결과: 6
```

### 2. `**kwargs` (Keyword Arguments)

- **형태:** 여러 개의 인자를 **딕셔너리(Dictionary)** 형태로 묶어서 받습니다.
- **특징:** `이름=값` 형태로 넘길 때 사용합니다. (별표가 두 개인 이유는 키와 값, 두 개가 한 쌍이기 때문이라고 기억하면 편해요!)
- **비유:** "각 물건에 이름표(포스트잇) 붙여서 박스에 담아와!"
```Python
def print_info(**kwargs):
    # kwargs는 {'name': 'Gemini', 'age': 2} 형태의 딕셔너리가 됨
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Gemini", age=2)
```

---

### 3. `func(*args, **kwargs)`가 쓰이는 진짜 이유

질문하신 코드 `result = func(*args, **kwargs)`는 보통 **"어떤 함수가 들어오든, 그 함수가 필요로 하는 인자를 그대로 전달해주겠다"**는 의미의 **대리인(Proxy)** 역할이나 **데코레이터**에서 많이 쓰입니다.

- **인자 전달 (Unpacking):** 여기서의 별표는 묶여 있는 데이터를 다시 풀어헤치는 역할을 합니다.
- `args`라는 보따리를 풀어서 순서대로 던져주고, `kwargs`라는 박스를 열어서 이름표대로 던져주는 것이죠.
    

---

### 요약하자면

|**문법**|**데이터 형태**|**사용 방식**|
|---|---|---|
|**`*args`**|**Tuple** (1, 2, ...)|위치 기반 인자 (Positional)|
|**`**kwargs`**|**Dictionary** {'a': 1, ...}|키워드 기반 인자 (Keyword)|

> **꿀팁:** 사실 이름이 꼭 `args`, `kwargs`일 필요는 없어요. 별표 하나(`*`)와 두 개(`**`)가 핵심입니다. 하지만 전 세계 파이썬 개발자들이 약속처럼 쓰는 이름이니 그대로 사용하시는 게 좋습니다.
