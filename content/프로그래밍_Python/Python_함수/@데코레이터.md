## 데코레이터란?

**"함수를 감싸서 기능을 추가하는 함수"**[](https://smart-worker.tistory.com/48)
```python 
# 데코레이터 없이
def hello():
    print("안녕")

hello()  # "안녕"

# 데코레이터 적용
@add_stars  # ← 이게 데코레이터
def hello():
    print("안녕")

hello()  # "*** 안녕 ***"

```

## 작동 원리

## 1. 기본 구조
```python 
def add_stars(func):  # func = 감쌀 함수
    def wrapper():
        print("***")
        func()  # 원본 함수 실행
        print("***")
    return wrapper

@add_stars  # hello = add_stars(hello)와 동일!
def hello():
    print("안녕")

hello()
# 출력:
# ***
# 안녕
# ***
```

**내부 흐름**:
```python
# @add_stars는 실제로는 이렇게 작동:
hello = add_stars(hello)
#       ↑ 데코레이터 함수가 원본 함수를 감싸서 새 함수 반환
```

## 2. 인자 받는 함수에 적용
```python
def log_execution(func):
    def wrapper(*args, **kwargs):  # 인자 받기
        print(f"[실행 시작] {func.__name__}")
        result = func(*args, **kwargs)
        print(f"[실행 완료] 결과: {result}")
        return result
    return wrapper

@log_execution
def add(a, b):
    return a + b

result = add(3, 5)
# 출력:
# [실행 시작] add
# [실행 완료] 결과: 8
```

## LangGraph - Tool 정의
```python
from langchain_core.tools import tool

@tool  # ← 함수를 LangGraph tool 객체로 변환
def get_real_estate_data(region: str) -> dict:
    """부동산 데이터를 가져옵니다."""
    return {"region": region, "price": 1000000}

# @tool이 하는 일:
# 1. 함수 → Tool 객체로 변환
# 2. docstring → tool description으로 사용
# 3. 타입 힌트 → tool schema로 사용

```

**내부적으로는**:
```python
get_real_estate_data = tool(get_real_estate_data) # tool() 데코레이터가 함수를 감싸서 Tool 객체 반환
```

## FastAPI - 라우트 정의
`app`은 `FastAPI`라는 클래스의 인스턴스(객체)이고, `get()`은 그 클래스 안에 정의된 **인스턴스 메서드**입니다.
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/apartments")  # ← URL 라우트 등록
async def get_apartments():
    return {"data": "아파트 목록"}

# @app.get()이 하는 일:
# 1. 함수를 FastAPI 엔드포인트로 등록
# 2. URL path 매핑
# 3. 자동 OpenAPI 문서 생성
```

**내부적으로는**:
```python
app.get("/apartments")(get_apartments) # get_apartments 함수를 HTTP GET 핸들러로 등록
```

`app.get()` 안에는 URL 경로뿐만 아니라 아주 많은 설정값들이 들어갈 수 있습니다.
```python
@app.get(
    "/apartments", 
    response_model=List[Apartment], # 응답 형태 지정
    status_code=200,                # 성공 시 상태 코드
    tags=["Real Estate"]            # 문서화용 태그
)
```


따라서 `get()` 외에도 HTTP 규격(Method)에 따라 다음과 같은 메서드들이 존재합니다.

- `@app.post()`
- `@app.put()`
- `@app.delete()`
- `@app.patch()`
- `@app.options()`

## Streamlit - 캐싱

```python
import streamlit as st

@st.cache_data  # ← 결과를 캐싱해서 재실행 방지
def load_data():
    # 시간 오래 걸리는 작업

# 2. 같은 인자로 호출 시 저장된 결과 반환
```

## 데코레이터 만들기 예시 _로깅(Logging)이 필요할 때
```python
import time
import logging

# 실행 시간을 로깅하는 decorator
def log_decorator(func):
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        end_time = time.time()
        logging.info(f'{func.__name__} 실행 시간: {end - start:.5f} 초') # logging 코드 추가
        return result
    return wrapper

@log_decorator
def my_function():
    time.sleep(2)

my_function()

# my_function 실행 시간: 2.00085 초
```

import logging 안한버전
```PYTHON
import time

def measure_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"{func.__name__} 실행시간: {end - start:.2f}초")
        return result
    return wrapper

@measure_time
def fetch_real_estate_data():
    time.sleep(2)  # API 호출
    return "데이터"

fetch_real_estate_data()
# 출력: fetch_real_estate_data 실행시간: 2.00초

```

## 재시도 데코레이터 (API 호출 시 유용)
```python
def retry(max_attempts=3):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for attempt in range(max_attempts):
                try:
                    return func(*args, **kwargs)
                except Exception as e: # 에러가 발생했는데 마지막 시도면 에러를 raise
                    if attempt == max_attempts - 1: # 0부터 시작하므로
                        raise
                    print(f"재시도 {attempt + 1}/{max_attempts}")
        return wrapper
    return decorator

@retry(max_attempts=3)
def call_api():
    # 가끔 실패하는 API
    return requests.get("https://api.example.com")

```

실행예시
```
시도 1/3
에러 발생: API 에러
재시도...
시도 2/3
에러 발생: API 에러
재시도...
시도 3/3 
에러 발생: API 에러
마지막 시도 실패! 에러 던짐
Exception: API 에러  ← 프로그램 중단

```

## raise의 두 가지 사용법

```python
# 1. 새로운 에러 발생
raise Exception("새 에러 메시지")  # 새로 만듦

# 2. 잡은 에러 다시 던지기
try:
    # 뭔가 실행
except Exception as e:
    raise  # 방금 잡은 e를 다시 던짐 (에러 정보 보존)

```

```python
# raise 없으면
except Exception as e:
    if attempt == max_attempts - 1:
        pass  # 아무것도 안 함
    # 에러 발생했는데 None 반환 → 버그!

# raise 있으면
except Exception as e:
    if attempt == max_attempts - 1:
        raise  # "3번 시도했는데 다 실패했어요!" 알림

```
