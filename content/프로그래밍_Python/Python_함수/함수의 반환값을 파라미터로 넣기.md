## 1. 일반 Python: 함수 반환값을 파라미터로 전달 (즉시 실행)
```python
def get_number():
    print("get_number() 실행")
    return 10

def add(x):
    return x + 5

# ✅ 일반 Python 방식
result = add(get_number())  # ← get_number() 즉시 실행, 반환값(10) 전달
#            ↑ 여기서 바로 실행됨!
print(result)  # 15

# 출력:
# get_number() 실행
# 15
```

## 2. FastAPI Depends: 함수 자체를 전달 (나중에 실행)
```python
from fastapi import Depends

def get_db():
    print("get_db() 실행")
    return "DB 연결"

# ❌ 일반 방식으로 쓰면?
def endpoint1(db = get_db()):  # ← 지금 당장 실행!
    #           ↑ 괄호 있음! 즉시 실행
    return db

# 문제: 서버 시작할 때 1번만 실행되고 끝
# 요청마다 실행 안 됨!

# ✅ Depends 방식
def endpoint2(db = Depends(get_db)):  # ← 함수 자체 전달, 나중에 실행
    #                     ↑ 괄호 없음! 함수 객체
    return db

# Depends가 요청마다 get_db() 실행해줌
```

```python
from fastapi import FastAPI, Depends

def get_db():
    print("  → get_db() 실행")
    return "MySQL 연결"

app = FastAPI()

print("=== 서버 시작 ===")

# ❌ 잘못된 방식
@app.get("/wrong")
def wrong_endpoint(db = get_db()):  # ← 서버 시작 시 1번만 실행!
    return {"db": db}

# 출력:
# === 서버 시작 ===
#   → get_db() 실행  ← 서버 시작할 때 1번만!
# 이후 요청해도 get_db() 안 실행됨

# ✅ 올바른 방식
@app.get("/correct")
def correct_endpoint(db = Depends(get_db)):  # ← 요청마다 실행!
    return {"db": db}

# 출력:
# === 서버 시작 ===
# (아무것도 안 나옴)
# 
# GET /correct 요청 시마다:
#   → get_db() 실행  ← 요청마다!

```

## 괄호 있음 vs 없음
```python
def get_value():
    return 10

# 1. 괄호 있음 - 함수 실행, 반환값 전달
x = get_value()  # x = 10 (반환값)
print(x)  # 10

# 2. 괄호 없음 - 함수 객체 자체 전달
y = get_value  # y = 함수 객체
print(y)  # <function get_value at 0x...>
print(y())  # 10 (나중에 실행)

```

## 실전 예시
```python
def get_number():
    print("→ 숫자 생성")
    return 42

# 일반 방식 (즉시 실행)
def process1(value = get_number()):  # ← 정의 시점에 실행!
    print(f"값: {value}")

print("=== 함수 정의 ===")
# 출력: → 숫자 생성  ← 벌써 실행됨!

print("\n=== 함수 호출 1 ===")
process1()  # 값: 42

print("\n=== 함수 호출 2 ===")
process1()  # 값: 42 (get_number() 재실행 안 됨!)

# Depends 방식 (나중에 실행)
from fastapi import Depends

def process2(value = Depends(get_number)):  # ← 함수 객체만 전달
    print(f"값: {value}")

print("\n=== FastAPI 엔드포인트 정의 ===")
# (아무것도 실행 안 됨)

print("\n=== 요청 1 ===")
# FastAPI가 get_number() 실행
# 출력: → 숫자 생성
# 값: 42

print("\n=== 요청 2 ===")
# FastAPI가 get_number() 다시 실행
# 출력: → 숫자 생성
# 값: 42

```

## 정리

|방식|문법|실행 시점|사용처|
|---|---|---|---|
|**일반 Python**|`func()` (괄호 O)|즉시 실행|일반적인 함수 호출|
|**FastAPI Depends**|`Depends(func)` (괄호 X)|요청마다 실행|의존성 주입|

**핵심:**

- `get_db()` = 지금 실행 → 반환값 전달
    
- `Depends(get_db)` = 나중 실행 → 함수 자체 전달 (FastAPI가 요청마다 실행)
    

**Python 자체는 함수 반환값을 파라미터로 전달 가능하지만, 그건 즉시 실행임. Depends()는 FastAPI의 특별한 기능으로 나중에 실행하도록 함!**
