```python
    # 캐릭터 이름순 정렬 (출력 순서 고정)

    sorted_results = sorted(GLOBAL_RESULTS, key=lambda x: x['character'])
```

`lambda`를 사용한 이유는 **"리스트 안에 들어있는 여러 데이터 중 어떤 것을 기준으로 정렬할지"**를 컴퓨터에게 간결하게 알려주기 위해서입니다.

초보자분들도 이해하기 쉽게 단계별로 설명해 드릴게요.

### 1. 왜 정렬 기준이 필요한가요?
현재 `GLOBAL_RESULTS` 리스트는 다음과 같은 구조로 되어 있습니다.
```python
GLOBAL_RESULTS = [
    {"character": "사트라", "results": [...]},
    {"character": "레티아", "results": [...]},
    {"character": "루파메스", "results": [...]},
    ...
]
```
단순히 `sorted(GLOBAL_RESULTS)`라고만 하면, 컴퓨터는 "사전(Dictionary) 뭉치들을 뭘 기준으로 줄 세워야 하지? 이름순? 아니면 결과 개수순?"이라며 당황하게 됩니다. 그래서 **"사전 안에 있는 `character`라는 글자를 보고 가나다순으로 정렬해!"**라고 기준을 정해줘야 합니다.

---

### 2. `lambda`가 쓰인 이유 (Anonymous Function)
`lambda`는 **이름이 없는 한 줄짜리 익명 함수**입니다. 정렬 기준을 정할 때 가장 많이 사용됩니다.

*   **코드 의미**: `lambda x: x['character']`
    *   `x`: 리스트 안에 들어있는 **사전 한 덩어리**를 의미합니다.
    *   `x['character']`: 그 사전 덩어리에서 **`character` 키에 해당하는 값**(예: "레티아")을 꺼내라는 뜻입니다.

#### 만약 `lambda`를 안 쓴다면?
원래는 아래와 같이 따로 함수를 만들어서 넣어줘야 합니다.
```python
# 1. 정렬 기준을 뽑아주는 함수를 따로 만듦
def get_name(item):
    return item['character']

# 2. 그 함수를 sorted의 key로 전달
sorted_results = sorted(GLOBAL_RESULTS, key=get_name)
```
하지만 이렇게 하면 고작 정렬 한 번을 위해 함수를 계속 정의해야 해서 코드가 길어집니다. `lambda`를 쓰면 이 모든 과정을 **단 한 줄로 간직**할 수 있습니다.


---
---

결론부터 말씀드리면, **`x`는 `GLOBAL_RESULTS` 전체가 아니라, 그 안에 들어있는 '데이터 한 덩어리(원소)'**를 의미합니다. 그리고 파이썬의 `sorted` 함수가 내부적으로 알아서 `x`에 값을 하나씩 넣어주기 때문에 `x = ...` 이라는 코드가 필요 없는 것입니다.

이해를 돕기 위해 **'컨베이어 벨트'** 비유를 들어 설명해 드릴게요.

---

### 1. 컨베이어 벨트 비유
`sorted(GLOBAL_RESULTS, key=lambda x: x['character'])` 코드가 실행되면 이런 일이 벌어집니다.

1.  **컨베이어 벨트 작동**: `GLOBAL_RESULTS`라는 상자 뭉치들이 컨베이어 벨트 위에 올라갑니다.
2.  **검사관 배치**: `lambda x: ...`는 벨트 옆에 서 있는 **'검사관'**입니다.
3.  **하나씩 꺼내기**: 벨트가 움직이면서 상자(`x`)가 하나씩 검사관 앞으로 지나갑니다. 
    *   첫 번째 상자가 오면 검사관이 그걸 `x`라고 부르며 열어봅니다.
    *   검사관은 "아, 이 상자의 이름(`character`)은 '레티아'구나!"라고 적어둡니다. (`x['character']`)
4.  **전체 비교**: 벨트 위의 모든 상자를 이런 식으로 다 확인한 후, 검사관이 적어둔 이름들을 가나다순으로 비교해서 벨트 위의 상자 순서를 다시 배치합니다.

---

### 2. 왜 `x = ...` 이 없어도 되나요?
`sorted`라는 함수가 내부적으로 **"내가 이 리스트를 한 바퀴 돌면서(for문), 각 아이템을 너가 만든 lambda 함수에 넣어줄게"**라고 이미 약속되어 있기 때문입니다.

컴퓨터 내부에서는 대략 이런 일이 일어납니다:
```python
# 우리가 짠 코드: sorted(GLOBAL_RESULTS, key=lambda x: x['character'])

# 실제 컴퓨터가 내부적으로 하는 일 (상상도):
결과물 = []
for 아이템 in GLOBAL_RESULTS:
    # 여기서 '아이템'이 우리가 쓴 'x'가 됩니다!
    기준값 = (lambda x: x['character'])(아이템) 
    # 이 기준값을 바탕으로 순서를 결정함...
```

---

### 3. 어떤 경우에 이런 게 가능할까요? (언제 사용하나?)
파이썬에서 **"리스트를 순회하면서 무언가를 처리하는 함수"**들은 대부분 이런 방식을 지원합니다.

*   **`sorted()`**: 정렬할 때 기준을 정하기 위해
*   **`max()`, `min()`**: 최댓값/최솟값을 찾을 때 기준을 정하기 위해
    *   `max(GLOBAL_RESULTS, key=lambda x: x['score'])` (점수가 가장 높은 사람 찾기)
*   **`filter()`**: 특정 조건에 맞는 데이터만 골라낼 때
    *   `filter(lambda x: x['character'] == '레티아', GLOBAL_RESULTS)`

### 요약하자면
`x`는 **"지금 내 손에 들려있는 이 데이터 하나"**를 부르는 임시 이름일 뿐입니다. `lambda` 함수는 "뭐가 들어올지는 모르겠지만, 일단 들어오면(x) 거기서 `['character']`를 꺼내서 나한테 줘!"라고 미리 주문서를 작성해 놓는 것과 같습니다.

포트폴리오 면접에서 "왜 여기서 lambda를 쓰셨나요?"라고 물어본다면, **"리스트 내의 딕셔너리 구조에서 특정 키값을 기준으로 정렬하기 위해, `sorted` 함수의 key 인자에 익명 함수를 전달하여 간결하게 구현했습니다"**라고 답변하시면 아주 훌륭합니다!
