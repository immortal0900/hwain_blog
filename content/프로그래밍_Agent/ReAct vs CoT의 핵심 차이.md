### 개념 비교

|구분|CoT (Chain of Thought)|ReAct (Reasoning + Acting)|
|---|---|---|
|핵심|생각 단계를 명시적으로 나열|추론 → **외부 행동** → 관찰의 **루프**|
|외부 액션|없음 (순수 추론)|필수 (Tool call, API 호출 등)|
|구조|Think → Answer|Think → **Act** → Observe → Think → ...|
|논문|Wei et al. (2022)|Yao et al. (2022)|

---

### 판단 기준

NPC가 응답 전에 자신의 생각을 먼저 쓰는 패턴을 보면:

```
[NPC의 생각]
"나는 지금 주인공에게 화가 나있다. 
하지만 감정을 드러내면 안 된다. 
차갑게 대응해야 한다."

[실제 응답]
"...별로 상관없어요."
```

이것은 **외부 도구 호출이나 관찰 루프가 없는**, 순수한 내면 추론 → 응답 패턴입니다.

따라서 이것은 **CoT**입니다. ReAct가 되려면 반드시 "행동(Act)" 단계(메모리 검색, DB 조회 등)가 있어야 합니다.

### 더 정확한 표현들

상황에 따라 더 정밀한 표현을 쓸 수도 있습니다:

- **CoT (Chain of Thought)** — 일반적으로 가장 맞는 표현
- **Inner Monologue** — "내면의 독백"으로, 캐릭터/페르소나 맥락에서 자주 쓰임
- **Scratchpad** — 초안 공간 개념으로 사용되기도 함
- **Persona-conditioned CoT** — 포트폴리오/논문에서 더 명확히 설명할 때
