-u는 --set-upstream의 줄임말입니다.

## 의미

로컬 main 브랜치가 원격 origin/main을 추적하도록 설정합니다.

## 효과

- 첫 푸시 후에는 git push만 입력해도 됩니다 (git push origin main 불필요)

- Git이 자동으로 어디로 푸시할지 알 수 있습니다

```
# 첫 번째 푸시 (upstream 설정)
git push -u origin main

# 이후부터는 이렇게만 해도 됨
git push

# -u 없이 푸시하면 매번 이렇게 써야 함
git push origin main
```
