### Git에서 과거로 돌아가는 두 방식

- **reset** : 원하는 시점으로 돌아간 뒤 이후 내역들을 지웁니다.
- **revert** : 되돌리기 원하는 시점의 커밋을 거꾸로 실행합니다. 즉 수행했던 내역을 반대로 실행합니다. 추가했다면 삭제하고 삭제했다면 다시 추가 그래서 결국 이전으로 돌아감
	- 거꾸로 되돌린 내역도 남겨야 하는 경우
	- 특정 버전만 제거하고 이후 버전은 남겨야 하는 경우
-

## 3. **reset** 하기 전 시점으로 복원해보기

백업해 둔 **.git** 폴더 사용

- `.git` 폴더 복원
- `git log`, `git status`로 상태 확인
- 아래 명령어로 현(마지막) 커밋 상태로 초기화

`   git reset --hard   `

- 💡 뒤에 커밋 해시가 없으면 마지막 커밋을 가리킴
- `lions.yaml` 삭제

### 🎯 **reset** 사용해서 revert 전으로 되돌아가기
`git reset --hard`
  

> [!NOTE] commit
>Git에서 **commit(커밋)** 한다는 것은 — 한마디로 — “**지금 스테이징 바구니에 모아 둔 파일들의 모습을 사진처럼 찍어, 프로젝트 앨범(저장소)에 한 장 추가한다**”는 뜻입니다. 
>이렇게 찍힌 사진(스냅샷)은 언제든 되돌아갈 ‘세이브 포인트’가 되어 주고, 팀원들과도 동일한 이력을 공유할 수 있게 해 줍니다.


### 💡 **커밋해버리지 않고** revert하기

`   git revert --no-commit (되돌릴 커밋 해시)   `
그냥 전으로 되돌리는 것 뿐만 아니라 뭐 좀 더 추가하기 위해 사용

- 원하는 다른 작업을 추가한 다음 함께 커밋
- 취소하려면 `git reset --hard`
