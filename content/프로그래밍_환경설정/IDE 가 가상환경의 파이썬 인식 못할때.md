:: [명령어 1] .vscode 폴더 생성
:: 존재 이유: Antigravity IDE(또는 VS Code 기반 에디터)가 현재 프로젝트에 대한 고유 설정 파일들을 보관할 전용 공간을 만들기 위해 존재합니다. 이미 앞서 설명해 드렸지만, 이 숨김 폴더 안에 설정 파일을 넣어야 IDE가 이를 사용자 설정으로 인식합니다.
:: 변수: 여기서 `.vscode`는 생성될 디렉토리(폴더)의 이름이자 에디터가 약속된 경로로 인식하는 고정된 시스템 폴더명 변수 역할을 합니다.
:: 나중에 쓰이는 곳: 설정 파일(`settings.json`)이 저장되는 물리적인 디렉토리 위치로 쓰이며, IDE가 켜질 때 혹은 재시작될 때 가장 먼저 이 폴더를 탐색하여 내부 파일들을 읽어옵니다.

```
mkdir .vscode
```

:: [명령어 2] settings.json 파일 생성 및 설정값 주입
:: 존재 이유: UI 버튼이 오작동하여 uv 설치 팝업을 띄우는 문제를 완전히 우회하기 위해, cmd의 echo 명령어를 통해 텍스트 형태의 설정 파일(.vscode\settings.json)을 직접 만들고 그 안에 올바른 파이썬 경로를 강제로 주입하기 위해 존재합니다. (이미 앞서 설명한 내용이지만, 시스템 동기화를 강제하는 핵심 원리이므로 다시 명시합니다.)
:: 변수 1 ("python.defaultInterpreterPath"): 이 변수는 현재 프로젝트에서 코드를 분석하고 실행할 때 기준으로 삼을 파이썬 엔진(실행 파일)의 절대 또는 상대 경로를 담아두는 문자열(String) 타입의 설정 키(Key) 변수입니다.
:: 변수 2 ("${workspaceFolder}\\.venv\\Scripts\\python.exe"): 이 변수는 실제 가상환경 속 파이썬 실행 파일이 위치한 값(Value) 변수입니다. 여기서 `${workspaceFolder}` 부분은 현재 열린 프로젝트 폴더의 절대 경로를 에디터가 알아서 동적으로 치환해주는 내장 변수입니다. 
:: 나중에 쓰이는 곳: 
:: 1. 에디터를 껐다가 다시 켤 때, IDE의 코드 분석 엔진(Pyre2 등)이 가장 먼저 이 "python.defaultInterpreterPath" 변수 값을 읽어와서 작업 환경을 구성할 때 쓰입니다.
:: 2. 에디터 하단에서 터미널을 새로 열 때, 이 경로에 있는 가상환경을 자동으로 활성화(Activate)해 주기 위해 쓰입니다.
:: 3. 가장 처음 겪으셨던 문제인 Ctrl+Click(정의로 이동) 시, 이 경로 안에 설치된 외부 패키지(deepeval 등)의 소스 코드 위치를 엔진이 역추적할 때 기준점 경로로 쓰입니다.


```
echo {"python.defaultInterpreterPath": "${workspaceFolder}\\.venv\\Scripts\\python.exe"} > .vscode\settings.json
```
