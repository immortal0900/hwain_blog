# 새로운 기기 세팅 절차

## 한마디 요약
**새 Windows PC에 AI Agent Developer 업무 환경을 꾸릴 때 순서대로 밟는 설치 체크리스트임. 브라우저 → 클라우드 → 지식관리 → 개발도구 → 협업도구 순으로 내려감.**

## 설치 순서와 이유

아래 순서는 "뒤 단계가 앞 단계를 이미 필요로 하는지"를 기준으로 잡았음. 예를 들어 `git`은 `cursor` 설치 전에 있어야 확장/설정을 바로 가져올 수 있음.

### 1단계: 브라우저 (Chrome)

- 다운로드: [google.com/chrome](https://www.google.com/chrome/)
- 로그인해서 북마크/확장 동기화
- **이유**: 이후 설치 링크들을 웹에서 찾아야 함

### 2단계: Google Drive

- 다운로드: [drive.google.com/drive/download](https://www.google.com/drive/download/)
- 로그인 후 동기화 폴더 위치 지정
- **이유**: 기존 문서/설정 파일이 이 드라이브에 있음. 가급적 **`C:\1.Project` 등 프로젝트 폴더는 Google Drive 동기화 대상에서 제외**할 것 (uv 하드링크 에러 방지: [[가상환경 재설치 uv]])

### 3단계: Obsidian (지식 관리)

- 다운로드: [obsidian.md/download](https://obsidian.md/download)
- Vault 경로는 Google Drive 동기화 경로로 연결 (노트는 동기화 대상이어도 무방)
- **이유**: 이 노트 자체를 비롯한 기존 지식을 바로 열어볼 수 있어야 다음 단계에서 참고 가능

### 4단계: Git

- 다운로드: [git-scm.com/install/windows](https://git-scm.com/install/windows)
- **아키텍처 선택법**:
    - Windows 설정 → 시스템 → 정보 확인
    - `64비트 운영 체제, ARM 기반 프로세서` → **ARM64 설치**
    - `64비트 운영 체제, x64 기반 프로세서` → **x64 설치**
- 설치 후 초기 설정:
```cmd
git config --global user.name "사용자이름"
git config --global user.email "이메일"
```
- **이유**: 다음 단계인 Cursor가 git 저장소 복제/동기화에 git 명령어를 내부적으로 씀

### 5단계: Cursor (에디터)

- 다운로드: [cursor.com](https://www.cursor.com/)
- 설치 후 관련 절차:
    - [[cursor 새로운기기에서 extensions 설치]]
    - [[cursor_새로운 기기_설정을 심볼릭 링크로 관리]]
    - [[cursor_새로운 기기에서 작업시]]
- **이유**: AI Agent 개발 핵심 IDE. 이 단계 이후 모든 코드 작업 진행

### 6단계: uv (Python 툴체인)

Cursor에서 파이썬 프로젝트를 열기 직전에 설치.

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**직접 확인**:
```cmd
uv --version
```

상세 세팅: [[가상환경 세팅 방법]]

### 7단계: 보조 도구

| 도구 | 용도 | 다운로드 |
|------|------|---------|
| Snipaste | 스크린샷/핀 기능 | [snipaste.com](https://www.snipaste.com/) |
| Discord | 커뮤니티/개발 협업 | [discord.com](https://discord.com/download) |
| 카카오톡 PC | 국내 연락 | [kakao.com](https://www.kakao.com/talk) |
| Slack | 업무 협업 | [slack.com/downloads](https://slack.com/downloads) |

## 세팅 후 점검 체크리스트

새 PC에서 작업 시작 전에 아래 명령을 한 번씩 쳐서 모든 도구가 살아 있는지 확인.

```cmd
chrome --version
git --version
uv --version
cursor --version
```

## 왜 이 순서인가 (의존성 그래프)

```
Chrome (링크 탐색)
  └─ Google Drive (기존 문서 동기화)
       └─ Obsidian (지식 참조)
            └─ Git (소스 관리)
                 └─ Cursor (IDE)
                      └─ uv (파이썬 툴체인)
                           └─ 프로젝트 작업 시작
```

Slack/Discord/카카오톡은 개발 도구 의존성과 무관하므로 아무 때나 설치 가능. 다만 보안 확인용 2FA 앱(스마트폰)과 연동되므로 업무 시작 전에는 해두는 것이 좋음.

## 주의 사항

- **경로 선택**: 파이썬 프로젝트 폴더는 **Google Drive/OneDrive가 동기화하지 않는 경로**에 두기 권장. 이유: uv 하드링크 모드가 클라우드 폴더에서 차단됨 (os error 396). 상세: [[가상환경 재설치 uv]]
- **2FA 백업 코드**: 각 서비스 로그인 시 2FA가 걸리면, 새 PC에서 처음 들어갈 때 백업 코드가 필요할 수 있음. 기존 기기에서 미리 확인
- **Cursor 확장 동기화**: 수동으로 하나씩 깔지 말고 [[cursor 새로운기기에서 extensions 설치]] 스크립트 사용

## 포함 관계

- **새 기기 세팅** (최상위 목표)
  - **인터넷/클라우드 레이어**: Chrome, Google Drive
  - **지식 관리 레이어**: Obsidian (Google Drive 내용 참조)
  - **개발 레이어**: Git → Cursor → uv → 프로젝트별 `.venv`
  - **협업 레이어**: Discord, Slack, 카카오톡
