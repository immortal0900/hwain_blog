# #가상환경/처음설치

## 계획 (의사코드)
- `uv 존재 여부 확인`  
- `프로젝트 폴더 준비`  
- `uv venv <폴더명>`으로 가상환경 생성`  
- `.venv\Scripts\activate`로 가상환경 활성화`  
- `uv pip install <패키지>`로 필요한 모듈 설치`  
- `uv pip list`로 설치 확인`  
- `필요 시 ipykernel 등록`  

### 3. 가상환경 생성
새로운 미니 연구실을 짓는 단계예요.
```
uv venv .venv
```
`.venv`는 환경 이름이라서 마음대로 바꿀 수 있고, 특정 파이썬 버전을 원하면:
```
uv venv .venv --python 3.11
```
처럼 옵션을 붙이면 돼요.

### 4. 가상환경 활성화
이제 연구실 문을 열고 들어가는 과정입니다.
```
.venv\Scripts\activate
```
프롬프트 앞에 `(.venv)` 같은 표시가 붙으면 성공이에요.

### 5. 패키지 설치
연구실에 필요한 도구(패키지)를 채워 넣어요.
```
uv pip install numpy pandas
```
`pyproject.toml`이나 `requirements.txt`가 이미 있다면:
```
uv pip install -e .
```
또는
```
uv pip install -r requirements.txt
```
로 한 번에 설치할 수 있어요.

### 6. 설치 확인
현재 연구실에 어떤 도구가 들어왔는지 확인해 봅니다.
```
uv pip list
```

### 7. 주피터 커널 등록 (필요 시)
노트북에서 새 환경을 커널로 쓰고 싶다면 이름을 붙여 등록해요.
```
python -m ipykernel install --user --name "my-env" --display-name "My Env"
```

마치 오래된 연구실 건물을 깨끗이 철거하는 느낌이죠.

### 3단계: 새 실험실 짓기
이제 `uv`라는 건설 로봇을 호출해 새 연구실을 세워요.
```
uv venv .venv
```
다른 이름을 쓰고 싶다면 `.venv` 대신 원하는 폴더명을 넣고, 특정 파이썬 버전이 필요하면 `--python 3.11` 같은 옵션을 붙이면 돼요.

### 4단계: 새 실험실 입장
새로 지은 연구실 문을 열고 들어갑니다.
```
.venv\Scripts\activate
```
프롬프트 앞에 `(.venv)`가 다시 붙으면 새 가상환경이 켜진 거예요.

### 5단계: 실험 장비 들여놓기
이제 필요한 도구(패키지)를 다시 채워 넣으면 됩니다.
```
uv pip install -e .
```
`pyproject.toml`에 적힌 패키지가 있다면 이 명령 하나로 전부 설치돼요. 개별적으로 넣고 싶다면 `uv pip install 패키지1 패키지2 ...`처럼 나열해도 되고, `requirements.txt`가 있다면 `uv pip install -r requirements.txt`로 한 번에 설치할 수 있어요.

### 6단계: 확인 및 커널 등록(필요 시)
설치가 잘됐는지 살짝 점검해 봐요.
```
uv pip list
```
쥬피터 노트북에서 새 가상환경을 커널로 쓰려면:
```
python -m ipykernel install --user --name "새환경이름" --display-name "보기 쉬운 이름"
```

#### 어려운 용어 풀이
- **가상환경**: 프로젝트마다 따로 쓰는 미니 연구실.
- **`deactivate`**: 연구실 밖으로 나와 기본 환경으로 돌아가는 명령.
- **`uv venv`**: 새 가상환경(연구실)을 짓는 명령.
- **`uv pip install`**: 연구실 안에 필요한 실험 도구(패키지)를 넣는 명령.
